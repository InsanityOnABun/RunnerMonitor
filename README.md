# RunnerMonitor
A Pebble watchface in the style of the 2026 videogame, Marathon. Developed through cloudpebble.repebble.com, assisted lightly by AI (no direct access to code given to AI, all edits made by human hand). Uses [Maratype](https://www.behance.net/gallery/227048755/MARATYPE-custom-display-font) font, by [Artyom Galinov](https://www.behance.net/iamimago), with permission.
